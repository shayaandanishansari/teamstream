personal work ledger

Now TM

Not a todo list. A live answer to "what's actually alive right now" — across every project you're running at once.

The problem it solves

Not boredom, not laziness — confusion. Too many live threads, no signal for which one is the real one right now.

The core unit

Work → Tasks, nested. A Work's state is derived from its tasks, never set by hand.

Three zooms, one map

Days

Horizontal scroll. Day-by-day, built first — resolves the "what's alive right now" confusion directly.

Week

Vertical stack. Seven days at a glance — enough range to see a pattern forming.

Month

Calendar grid. Where deadlines live — things due later, not active today, still visible.

Time

Daily / weekly / monthly rollups. Real hours per task, not guesses — the number that tells you what to actually keep doing.

Notes, always current

Day-level notes, visible on the calendar. The latest one is always pinned — a single line of context you never have to go dig for.

Who it's for

Freelancers, indie builders, small mission-driven teams — anyone running several self-owned threads at once with no external structure imposed on them. Built selfishly, for one person, on purpose.
